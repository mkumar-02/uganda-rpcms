# RPCMS Partner Onboarding API

Staff-facing FastAPI service for Uganda RPCMS partner onboarding.

## Capabilities

1. Partner application (URSB / NGO Bureau identifiers)
2. Automated compliance checks (stub adapters; replace with live bureaus)
3. MoU attachment + status (UGPass e-sign later)
4. Locations (admin large / small areas, service points)
5. Approval → provision stubs for Registry **Agent** + PBMS **Agency/Program**

## Install

```bash
pip install -e ./ngo/backend
```
